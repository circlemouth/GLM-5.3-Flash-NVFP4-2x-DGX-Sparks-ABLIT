## Static AXL-ABLIT weight distribution

The static checkpoint is distinct from the optional BF16 runtime overlay. Its inputs are owned by [the AXL-ABLIT lock](../config/axl_ablit.lock.json): the public AXL checkpoint, the NVIDIA reproduction source, and the Dealign donor. The [derived-checkpoint design](axl-ablit-derived-checkpoint.md) owns the conversion contract; the [qualification report](axl-ablit-qualification.md) owns generated-artifact identities and measured results. A processed key is not necessarily a byte-changed tensor; in the reported artifact the native MTP donor payload matches the AXL payload.

The pinned source models state MIT terms. For an artifact verified against those inputs, prepare a separate weight distribution under MIT, retaining the upstream copyright, permission and disclaimer text. Preserve the NVIDIA and AXL model cards and the Dealign card and license as provenance records. The cards' upstream results are not measurements of this derived checkpoint. The Git source code remains Apache-2.0; the conversion tool's terms do not by themselves relicense its model output. Additional materials require their own review.

The numerical reference converter is identified in the lock. Its Apache-2.0 notice is retained in [LICENSES](../LICENSES/tenhkspark-Apache-2.0.txt) and [third-party notices](../THIRD_PARTY_NOTICES.md). This reference attribution does not claim that every source function was copied. MIT grants are conditional on preserving the applicable notices and are not a warranty of the complete upstream rights chain.

## Keep release documentation outside the checkpoint

The derived-checkpoint verifier checks hashes of all recorded auxiliary files, the exact recursive file set, and the conversion-module digest. Adding a new license file inside the checkpoint, replacing its inherited README, or changing the converter merely to add a comment can invalidate the existing artifact. Do not modify the generated manifest, loosen verification, or rebuild the model as a licensing shortcut.

A separate release may use a wrapper directory: put the public model card, MIT license, upstream notices and reviewed public provenance at the wrapper root; keep the original checkpoint bytes and relative file names in a `checkpoint/` child directory. Point the runtime's derived-checkpoint path at that child, not the wrapper root. Keep downloader caches and new documentation outside it. This is a packaging layout, not a qualification of a new deployment or a promise of generic Hub-root loading.

Before release, match the local artifact with its generation evidence, archive the exact pinned notices, inspect the original manifest for private information, and run the existing verification against the unchanged checkpoint. A public summary does not replace the manifest used by the runtime. If the original manifest cannot be published safely, stop that packaging route rather than silently redacting a hash-pinned file. External publication remains a separate authorized operation.
